# Release checklist

Before publishing a benchmark-harness update:

1. `make check` passes.
2. The retained reference trajectories re-analyze to the expected metrics.
3. Difficulty outputs, when changed, pass their scientific sanity checks.
4. The retained reference runs pass validity checks.
5. Provenance records remain complete and path-safe.
6. A fresh live integration smoke is run when runner/adapter behavior changed.
7. No sandbox resources remain after a live smoke.
8. Publishable files pass the secret scan.
9. Publishable files contain no machine-specific paths or identifiers.
10. Generated bytecode/caches are absent.
11. Only an explicit public-file allowlist is staged.
12. `git diff --cached --check` and a staged-content review pass before push.

An integration smoke validates plumbing; its score is not a benchmark result.
