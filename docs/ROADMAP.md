# Roadmap

- broader EvoCode coverage
- repeated runs for reliability/variance
- multiple model/provider configurations
- event-level token/cache/tool telemetry with event-identity deduplication
- isolated-round/reference controls for intrinsic difficulty
- standardized shareable run bundles
- additional long-horizon backends

Not planned for v0.1: an opaque single score or a dashboard before the metrics stabilize.
